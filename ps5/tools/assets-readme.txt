Put Budokai 3's files here, from your own Budokai HD Collection disc.

Copy the disc's DBZ3 folder into this folder, so it looks like this:

  Assets/DBZ3/yae3_xenon.xex
  Assets/DBZ3/us/data_cmn.afs
  Assets/DBZ3/us/...

(Copying the DBZ3 folder's contents straight into Assets works too.)
Recomp Store sets this up for you from your disc image.

DRAGON BALL Z BUDOKAI 3 - PS5 (version 0.0.5 Beta)

1. Copy this PPSA93004 folder to /data/homebrew/ on your PS5, so you have
   /data/homebrew/PPSA93004/eboot.bin (not a folder inside another folder).
2. Copy the DBZ3 folder from your own Budokai HD Collection disc into
   /data/homebrew/PPSA93004/Assets/
3. Run the ShadowMountPlus payload again so it picks up the new app.

Updating from an earlier build: copy the new files over the old folder.
Your Assets folder and saves stay.

No game files are included.
